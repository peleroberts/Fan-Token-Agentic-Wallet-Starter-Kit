Use cases

Five examples. Real payment flows.

Each example is a runnable TypeScript file with a header explaining the use case, who it's for, and what to wire up for production.

⚽
Match-Day Wallet
Detects match day, checks CHZ balance, evaluates sentiment, and proposes purchasing a ticket or streaming pass automatically.
npm run example:matchday
📺
Streaming Payments
Pay-per-minute CHZ stream to a content provider. Fan pays only for what they watch — perfect for exclusive post-match content.
npm run example:streaming
🗳️
Governance Agent
Reads active club proposals, reasons about them based on fan preferences, and autonomously casts votes with human approval.
npm run example:governance
🎁
Loyalty Rewards
Monitors available loyalty rewards and airdrops, prioritises by expiry, and proposes claiming them — all in one automated flow.
npm run example:loyalty
📊
Multi-Club Portfolio
Hype-scores BAR, CITY, and PSG simultaneously. Ranks by signal strength and proposes a rebalancing swap if the opportunity is clear.
npm run example:portfolio
Features

Everything you need to start.

A complete, opinionated scaffold. Each layer is independently replaceable.

🔌
LLM-Agnostic
Claude and OpenAI built-in. Implement one interface to add any model — Gemini, Ollama, Groq, or your own.
⛓️
Chiliz Chain Native
Full EVM support via viem. Mainnet (88888) and Spicy testnet (88882) pre-configured. Works out of the box.
💸
Payment Tools
Direct payments, streaming micropayments, DEX swaps, governance votes, loyalty claims — all as agent tools.
🔥
Hype Score Engine
0–100 trading signal from match results + news sentiment. Transparent, extendable, and mock-data friendly.
🛡️
Guardrails
Daily spend caps, per-tx limits, approval thresholds — enforced at the execution layer. The LLM cannot bypass them.
👤
Human-in-the-Loop
Confirm mode requires y/N approval before every transaction. Auto mode acts within caps. Your choice.
🧪
Mock-First
All external data falls back to mock data. The full agent loop runs from first clone — no API keys required.
📄
Integration Stubs
DEX swaps, governance, streaming protocols, and rewards are stubbed with clear // NOTE comments and code examples.

Architecture

Four clean layers.

Each layer is independently replaceable. Swap the LLM, the wallet signer, or the data source without touching anything else.

src/ ├── llm-adapters/ ← LLMAdapter interface + Claude, OpenAI adapters ├── agent/ ← Multi-turn agent loop (LLM-agnostic) ├── mcp-tools/ ← Tool definitions + executor (payments, swaps, votes) ├── wallet/ ← Chiliz Chain wallet client (viem) ├── guardrails/ ← Spend policy engine (enforced at execution layer) ├── data/ ← Sports feed + Hype Score calculator └── config/ ← Chain config + Fan Token registry examples/ ├── match-day-wallet/ ← Ticket + stream purchase on match day ├── streaming-payments/ ← Pay-per-minute content access ├── governance-agent/ ← Autonomous proposal voting ├── loyalty-rewards/ ← Auto-claim rewards and airdrops └── multi-club-portfolio/ ← Multi-token Hype Score + rebalancing
